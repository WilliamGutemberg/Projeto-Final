# Saúde sem Filas

Projeto final de Front End. Site que organiza o fluxo de pacientes em clínicas e hospitais:o paciente agenda a consulta, faz check-in digital e acompanha a fila de casa, sem fazer volume na recepção.

## Tecnologias 

HTML5 e CSS3

## Como abrir

Abrir 'html/entrar.html' no navegador.
